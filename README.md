# Quoxient Website

Production-ready static release of the Quoxient website approved on September 1, 2026.

## Pages

The site is a single-file, tabbed experience with seven URL-hash routes:

- Home
- Individuals
- Organizations
- Blueprint
- AIQ + Products
- Case Studies
- About

## Deployment

Vercel serves `index.html` as the site root. The deployment is intentionally dependency-free: no build command, package manager, or framework is required.

## Content governance

The governed content package and release history are maintained in the Quoxient 2.0 website area of the shared Cadence 2.0 team vault.
